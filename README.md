## 🚀 Featured Engineering Work

### 🗄️ [Distributed File Storage System](https://github.com/urvashikohale/GFS_Google_File_System)

GFS-inspired distributed storage system designed for reliability, concurrency, and failure recovery.

`C++` `gRPC` `Multithreading` `Distributed Systems`

- Replication factor of three with heartbeat-based health monitoring
- Failure detection and automatic chunk-server recovery
- Per-chunk locking with strict lock ordering for concurrent operations
- Lease-based consistency supporting 100+ concurrent requests

### 🎓 [EduTok Engine](https://github.com/urvashikohale/EduTok-Engine---Multimodal-AI-Agent)

Multimodal AI platform that transforms educational documents into interactive learning content.

`Python` `FastAPI` `Celery` `Redis` `RAG` `AWS`

- Document ingestion, retrieval, script generation, and video assembly pipeline
- Parallel background processing for scalable asynchronous workloads
- Retrieval-augmented generation using vector search and contextual grounding
- Reduced end-to-end content generation from hours to minutes

### 📊 Real-Time Event Analytics

High-throughput streaming pipeline for ingesting, processing, and storing real-time events.

`Kafka` `Python` `PostgreSQL` `Streaming Systems`

- Processes approximately 30,000 events per minute
- Reduced processing latency from approximately four seconds to under one second
- Uses batching, bulk database writes, and consumer-lag monitoring
- Supports backpressure handling and horizontal consumer scaling

### 🥗 VitaLens

Vision-language nutrition assistant that analyzes meals and provides grounded nutrition insights.

`GPT-4o` `Qwen-VL` `LLaVA` `FastAPI` `React` `USDA FoodData Central`

- Evaluates multiple vision-language models for food understanding
- Grounds nutrition estimates using verified USDA food data
- Combines multimodal reasoning with an interactive full-stack experience
